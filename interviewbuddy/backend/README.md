# InterviewBuddy Backend

Spring Boot 3 / Java 21 REST API. See the root [README.md](../README.md) and [docs/setup.md](../docs/setup.md) for full setup instructions.

Quick start:
```bash
mvn spring-boot:run
```

Run tests:
```bash
mvn test
```

Package:
```bash
mvn clean package
java -jar target/interviewbuddy-backend-1.0.0.jar
```

Environment variables are documented in [`.env.example`](../.env.example) at the repo root.
