# InterviewBuddy Frontend

React + TypeScript + Vite + Tailwind CSS single-page app. See the root [README.md](../README.md) for full setup instructions.

Quick start:
```bash
npm install
npm run dev
```

Build:
```bash
npm run build
```

The dev server proxies `/api/*` to `http://localhost:8080` (see `vite.config.ts`) — start the backend first.
